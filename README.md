# 🎓 E 410: Phonetics & Phonology — Interactive Study Guide

Interactive viva preparation web app for **E 410: Phonetics and Phonology** (Department of English, Jahangirnagar University).

## 🚀 Live Site
Hosted at: [https://410.tmadhu.me](https://410.tmadhu.me)

## ✨ Features
- 🔊 **Interactive IPA Audio**: Click any IPA symbol to hear British English pronunciation via Web Speech API.
- 📱 **Fully Mobile & Smartphone Optimized**: Touch targets, responsive tables, quick search, and collapsible sections.
- 🌙 **Dark & Light Theme**: Seamless toggle with local storage memory.
- 🔍 **Fast Search**: Instant topic search in header and sidebar.
- ✅ **Interactive Viva Checklist**: Track preparation progress locally.
- 📊 **Reading Progress Tracker**: Real-time scroll progress indicator.
